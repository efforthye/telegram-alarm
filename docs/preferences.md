# 알림 형식 원칙

- 알림에 이모지, 가운뎃점(·), 긴 대시(—), 화살표 쓰지 않음. 줄바꿈, 쉼표, 괄호, 콜론, "목표:", "손절:" 같은 글자 라벨로 정리.
- 한 줄 알림 싫어함. 여러 줄, 굵은 소제목으로 깔끔하게. 제목은 "주식 매수 신호: 종목명"처럼 무슨 일인지 바로 보이게 ("true 알람" 같은 표현 금지).
- 종목명 자체를 알파스퀘어 링크로 (https://alphasquare.co.kr/home/stock-summary?code=코드), 옆에 따로 "알파스퀘어" 글자 붙이지 않음.
- 브리핑에 밤사이 미국 증시, 환율, 유가, 백테스트 문구 넣지 않음 ("차트 보는 사람은 안 본다").
- 여러 신호는 묶음 알림 1개(종목당 2줄), 1개일 때만 상세.
- 가짜/샘플 표시 말고 실제 데이터로 테스트 알림 보내길 원함.
- 판단 요청에 짧게 true/false 로 답하라고 할 때가 있음. 부정적 요소 정리는 "종목: ~, ~, ~" 한 줄 형식.
- 세부 확인보다 "알아서 잘 되게" 진행하길 선호. 단, 토큰 입력·계정 생성 등은 직접 하게 안내.

**Why:** 사용자가 여러 번 직접 지적한 형식 선호.
**How to apply:** [알림 시스템](system.md) 알림 문구를 만들거나 종목 분석을 답할 때 항상 적용.
