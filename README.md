# telegram-alarm

코인/주식 매수·매도 조건을 GitHub Actions에서 주기적으로 확인하고 텔레그램으로 알려주는 감시 봇.
투자 권유가 아니라, 정해 둔 규칙(RichClub 팀 메모 기반 차트 매매 규칙)의 통과 여부를 알려줄 뿐이다.

## 구성

| 폴더 | 내용 |
|---|---|
| `coin/scan.py` | 업비트/빗썸 상장 코인 중 BTC 대비 강세 코인 탐지 (바이낸스 시세) |
| `coin/notify.sh` | 텔레그램 발송 |
| `stock/stock_scan.py` | 코스피200·코스닥150 + 관심 종목 매수 조건 판정 (Yahoo 시세) |
| `stock/backtest.py` | 규칙 백테스트 (`python3 stock/backtest.py 375`) |
| `monitor/monitor.py` | 실시간 감시, 일일 리포트, 텔레그램 명령 처리 |
| `monitor/exits.py` | 보유·신호 종목 매도 판정 |
| `monitor/holdings.py` | 보유/관심 종목 관리 |

상태(보유 목록, 신호 추적, 로그)는 `state` 브랜치에 자동 저장된다.

## 판정 규칙 요약

- 시장 조건(엄격 모드): 코스피(주식)/BTC(코인) 종가가 60일선 위이고 60일선이 상승 중일 때만 매수 신호
- 주식 매수: A(6조건: 양봉, 5·20일선 정배열, 60일선 위, MACD·스토캐스틱·OBV 정배열) 또는 B(볼린저18 상단 첫 터치 + OBV + BWI 상향), 침체·훼이크 구간 제외
- 강한 자리: 일/주/월봉 동시 정배열, 골든보, 이평선 밀집 후 출발, 쌍바닥, 기준선 돌파 (A/B 통과 종목에 가산)
- 매도: 손절선, 피보나치 78.6% 이탈, 침체, 60일선 하락 중 그 아래, RSI 70 하방이탈, 10일선 종가 이탈, 5일선 꺾임 등

## 실행 방식

- `alarm-bot` 워크플로가 상시 실행된다 (약 5시간 40분마다 스스로 다음 실행을 띄움, 매시 7분 예약은 끊겼을 때 재시작용)
- 텔레그램 명령은 롱폴링으로 바로 처리 (보통 수 초 안에 답장)
- 평일 09:00~15:45 KST 30분마다 감시, 그 외 1시간마다
- 평일 08:30 아침 브리핑, 16:30 마감 브리핑, 주말 09:00 코인 브리핑
- `alarm-monitor` 워크플로는 수동 실행 전용 (test, report-*)

## 설정

1. 텔레그램에서 @BotFather → `/newbot` 으로 봇을 만들고 토큰을 받는다.
2. 만든 봇과 채팅을 열고 아무 메시지나 보낸다.
3. 내 채팅 ID 확인: @userinfobot 에게 메시지를 보내면 Id 숫자를 알려준다.
4. 저장소 Secrets 등록 (터미널에서 실행하면 값을 입력하라고 묻는다):
   ```bash
   gh secret set TELEGRAM_BOT_TOKEN -R efforthye/telegram-alarm
   gh secret set TELEGRAM_CHAT_ID -R efforthye/telegram-alarm
   ```
5. Actions 탭 → alarm-monitor → Run workflow → mode `test` 로 연결 테스트.

## 텔레그램 명령 (봇 채팅에 보내기)

```
검색 현대차                 종목 분석 (조건, 가격, 보유 시 판정)
검색 SOL                    코인 분석
보유 한미사이언스 55200     보유 종목 등록 (매도 신호 감시)
보유 SOL 85.2               코인 보유 등록
삭제 한미사이언스            보유 삭제
목록                        보유 목록
관심 제닉스로보틱스          관심 종목 등록 (매수 조건 감시)
관심삭제 제닉스로보틱스
관심목록
```

명령은 다음 실행 때(최대 30분~1시간 뒤) 처리된다. TELEGRAM_CHAT_ID 채팅에서 온 메시지만 받는다.
